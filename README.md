# eCommerce-Application
Online store built with Vue, CommerceTools, TypeScript, and Vite.

## Technology Stack

### Core Technologies
- Vue
- TypeScript
- Vite

### Code Quality & Formatting
- ESLint
- Prettier
- StyleLint
- Husky
- lint-staged

### Testing
- Vitest

## Project Setup

### Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/into0/eCommerce-Application.git
2. Navigate to project directory:
    ```bash
    cd ecommerce-application
3. Install dependencies:
    ```bash
    npm i

## Available scripts

### Development
```npm run dev``` - Starts development server\
```npm run preview``` - Previews production build locally

### Building
```npm run build``` - Creates production-ready build

### Code Quality
```npm run lint``` - Runs ESLint\
```npm run lint:fix``` - Runs ESLint --fix\
```npm run format``` - Formats with Prettier\
```npm run stylelint``` - Runs StyleLint\
```npm run stylelint:fix``` - Runs StyleLint --fix

### Testing
```npm run test``` - Runs Vitest
